บทวิเคราะห์รายละเอียด — Weekly Detail

By Type Shop, Region, Area & Shop · updates with the Week selector and every filter
WoW = week-over-week. "Full week" totals Week B's actuals against Week A's full 7 days, which understates Week B while it is still in progress; "Like-for-like" instead compares the same number of elapsed days in both weeks, so the read stays fair mid-week. Target (MTD and weekly) is always the full period's plan — the whole month, or the whole 7-day week — never prorated to the as-of date; Actual is whatever has posted so far. The effective as-of date is the most recent date with data for the selected product, or the earliest common date across products when "All" is selected. Area, region and product breakdown charts and tables ignore only their own dimension's filter so every category stays visible for comparison; all other filters still apply.
